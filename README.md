# Perio-journal

Steg-for-steg journalføring av periodontittbehandling etter HELFO stønadspunkt 6a og 6b.

**Bruk på nett:** https://marval1990.github.io/Perio-journal/

Velg timen du setter opp, kryss av og fyll inn, og kopier ferdig journaltekst inn i Opus:

- Fase 1 – Undersøkelse og behandlingsplan (takst 1 / 2 / 3)
- Fase 2 – Depurasjon (6 + 501 × n), reevaluering (4 eller 501), kirurgi (501 + 502), postop-kontroll (501 eller 5)
- Fase 3 – Vedlikehold (501)
- 6b – Rehabilitering ved tanntap pga. grav marginal periodontitt

Siden regner ut antall 501 ut fra behandlingstid (min. 30 min, deretter per 30. minutt), varsler om grensen på 14 × 501 per kalenderår og sjekker HELFO-kravene for hver time.

Ingen pasientdata lagres eller sendes – alt kjører i nettleseren. Kontroller alltid mot gjeldende regelverk.
